# Priyanshu Kumar — Animated Portfolio

A responsive, animation-rich personal portfolio built with plain HTML, CSS and vanilla JavaScript. No frameworks, no build step, no trackers.

**Live:** https://priyanshkk.github.io

## Features

- Typewriter hero headline with rotating roles
- Interactive particle canvas with pointer lines
- Scroll-reveal sections, animated skill bars and stat counters
- Hover-tilt project cards and a live tech marquee
- Sticky navigation with scroll progress and active-section highlighting
- Mobile menu, copy-to-clipboard email, toast feedback
- Respects `prefers-reduced-motion` for accessibility

## Files

- `index.html` — semantic page structure and content
- `styles.css` — design system, layout, animations and responsive rules
- `script.js` — interaction layer (no dependencies)

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
