# Priyanshu Kumar — 3D Portfolio

A premium, motion-rich personal portfolio built with HTML5, Tailwind CSS, vanilla ES6+, Three.js, GSAP + ScrollTrigger and Lenis. Static GitHub Pages build — no bundler, no trackers.

**Live:** https://priyanshkk.github.io

## Experience

- Cinematic preloader with 0–100% counter and curtain reveal
- Interactive Three.js hero (wireframe core, orbital rings, reactive particle halo) with CSS fallback
- Lenis momentum scrolling synced to the GSAP ticker
- Kinetic headline reveals, section headings, stat counters and scroll progress
- Magnetic custom cursor with contextual labels plus magnetic buttons/socials
- 3D-tilt bento grid for About, stats, motion reel, philosophy and current focus
- Pinned horizontal project archive with parallax and hover depth
- Hover-reveal expertise list with a cursor-following image preview
- Particle-wave contact canvas, one-click email copy and toast feedback
- Fully responsive, reduced-motion aware, CDN failures degrade gracefully

## Files

- `index.html` — page structure, SEO metadata and JSON-LD
- `styles.css` — design system, glassmorphism, motion and responsive rules
- `script.js` — interaction layer (preloader, scroll, 3D, canvas, utilities)
- `assets/` — original artwork and motion reel created by Priyanshu Kumar

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
